# calculator

A simple, working calculator app in Flutter.

## Structure

```
calculator/
├── lib/
│   ├── main.dart                       # App entry point
│   ├── screens/
│   │   └── calculator_screen.dart      # UI: display + button grid
│   ├── widgets/
│   │   └── calc_button.dart            # Reusable round button
│   └── services/
│       └── calculator_engine.dart      # All arithmetic logic (no UI)
├── test/
│   └── calculator_engine_test.dart     # Unit tests for the engine
├── pubspec.yaml
└── analysis_options.yaml
```

## Features

- Addition, subtraction, multiplication, division
- Decimal input
- Sign toggle (±) and percent (%)
- Clear (C)
- Chained operations (e.g. 2 + 3 × 4 calculates left to right, like most
  basic calculators — not full order-of-operations/PEMDAS)
- Division by zero shows "Error" instead of crashing

## Getting started

This was built without the Flutter SDK/native platform folders, since those
are generated by the `flutter` CLI itself. To run it:

1. Extract/copy this folder wherever you keep your Flutter projects.
2. From inside the `calculator` folder, run:
   ```bash
   flutter create --project-name calculator .
   ```
   This fills in the missing android/, ios/, web/, etc. folders without
   touching lib/, test/, or pubspec.yaml.
3. Install dependencies:
   ```bash
   flutter pub get
   ```
4. Run the app:
   ```bash
   flutter run -d edge
   ```
   (or `-d chrome`, or an Android emulator/device id — whatever you have
   set up)

## Running the tests

```bash
flutter test
```
